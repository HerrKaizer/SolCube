# Suite

Android app for vivo / OriginOS phones (tested on OriginOS 7). Needs [Shizuku](https://shizuku.rikka.app/) running.

Features: Circle to Search triggers (two-finger hold, power-button hold), frame interpolation and super resolution for games, temperature overlay, audio mixing ("Play together"), routines, double power press, stream-to-laptop.

Download the APK from the Releases page.
